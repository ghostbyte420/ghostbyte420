## uoAvox: A Custom Game Engine for Hobbyists

**Unleash Your Creativity**</br>

uoAvox is a custom game engine tailored for hobbyists and developers passionate about Ultima Online™ but eager to craft entirely original experiences. Rooted in the Ultima Online™ RunUO emulator (v2.7), it’s completely free from Ultima Online’s code and constraints - giving users the power to design unique worlds, storylines, and gameplay experiences with complete creative freedom.

---

**Key Features**
- Independent System: No reliance on official Ultima Online software. uoAvox provides its own custom server and client, developed from scratch by volunteer and pay-to-play contributors.</br></br>
- Sandbox Creativity: Users can design their own worlds, storylines, quests, and gameplay mechanics. The engine supports both the original Ultima Online graphics and fully custom assets.</br></br>
- Total Customization: The project emphasizes over-the-top customization, offering a vast array of tools and options for users to tailor their games to their imagination.</br></br>
- Non-Emulation Focus: Unlike traditional RunUO-based projects, uoAvox cannot be used to create an Ultima Online emulation server. Instead, it serves as a blank canvas for building entirely new games or genres.</br></br>

---

**Requirements**

*Developers* </br> this project requires proficiency in C#, the ability to work with XML and JSON files, and a solid understanding of object-oriented programming; making it a rewarding challenge for developers at any skill level.</br></br>
*Artists and Animators* </br> This project requires the ability to create artwork in a 1:1 (drawn to scale ratio), 2.5D (to simulate depth while remaining fundamentally 2D), military isometric perspective (a top-down or slightly angled 45 degree view).</br></br>
*Musicians* </br> This project requires sound effects and regional compositions that will vary depending on the genre of server is being made. Many people outsource for this service for those who wish to make some money. </br></br>
